# Vishwa — Student Developer Portfolio (B.Tech AI & Data Science)

A 5-star, responsive personal brand and engineering portfolio for **Vishwa**, a 2nd-year B.Tech Artificial Intelligence & Data Science student at **Prince Dr. K. Vasudevan College of Engineering and Technology, Chennai**.

Built with **React 19**, **Vite**, **React Router**, and **Modern CSS**. Designed with a **Dark Tech** aesthetic inspired by Linear, Apple, and Vercel, paired with a functional, persisted **Light Mode toggle**.

│   ├── components/
│   │   ├── icons/BrandIcons.jsx  # SVG brand icons (GitHub, LinkedIn, Instagram)
│   │   ├── Navbar.jsx            # Sticky navigation with mobile drawer
│   │   ├── ThemeToggle.jsx       # Dark / Light theme toggle
│   │   ├── ScrollProgress.jsx    # Top reading progress indicator

│   │   ├── Projects.jsx          # Bento grid with category filters
│   │   ├── ProjectCard.jsx       # Individual project card with live mockups

│   │   ├── Education.jsx         # B.Tech coursework & Prince Dr. K. Vasudevan College
